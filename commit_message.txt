Configure GitHub Pages deployment and update contact forms / GitHub Pages dağıtımı yapılandırıldı ve iletişim formları güncellendi

- Updated the base URL in the Hugo configuration and README to point to the new GitHub Pages domain.
- Migrated the contact forms (TR/EN) from Netlify to Forminit.

TR:
- GitHub Pages'e otomatik dağıtım (deployment) yapabilmek için GitHub Actions iş akışı (.github/workflows/hugo.yaml) eklendi.
- Hugo yapılandırma dosyasındaki (hugo.toml) baseURL ve README içerisindeki canlı site bağlantısı yeni GitHub Pages adresine göre güncellendi.
- İletişim (contact) sayfalarındaki formlar Netlify altyapısından çıkarılarak Forminit servisine taşındı.
